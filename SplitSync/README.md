# SplitSync

A modern MERN-based expense sharing platform for managing group expenses and balances efficiently.

## Features
- Group expense splitting
- Balance tracking
- JWT Authentication
- Analytics dashboard
- Responsive UI

## Tech Stack
- React
- Node.js
- Express.js
- MongoDB

## Installation

```bash
npm install
npm run dev
```
